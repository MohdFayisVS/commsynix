# COMSIGN — Quick Start Guide (Preview)

COMSIGN is a planned local-network digital signage system from COMMSYNIX.

**Release status:** Windows Server installer and Android Player APK are still under development. This guide describes the intended workflow, not a currently operational server-to-player product.

## Intended setup
1. Install COMSIGN Server on a Windows PC on the local network (when released).
2. Install COMSIGN Player on a compatible Android TV or Android TV box (when released).
3. Connect both devices to the same LAN or Wi-Fi for pairing and media synchronization.
4. In the server dashboard, add a screen, upload images/videos, create a playlist, and assign it to that screen.
5. Trigger **Push Now** or wait for automatic synchronization.
6. Confirm the player reports that all assigned files were downloaded and verified before disconnecting it.
7. After successful sync, the player should continue playback from persistent local storage without LAN or internet connectivity.

## Notes
- Internet is not intended to be required for local content sync.
- Reconnect the player to update content or view its live status.
- Scheduled content depends on a correct device clock.
- Smart TVs running Samsung Tizen or LG webOS cannot install standard Android APKs; use a compatible external Android player.
- Do not use for safety-critical emergency messaging without separately validated redundancy and supervision.
